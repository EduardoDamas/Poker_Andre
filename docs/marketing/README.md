# CAPA CONTEST — Materiais para a Agência de Marketing

Pacote de materiais para o site informativo e a campanha. Atualizado para o build **1.0.3+9**.

## Conteúdo deste pacote
| Arquivo | O que é |
|---|---|
| `GUIA_DE_INSTALACAO.md` | Passo a passo de instalação do app (link direto, fora da Play Store) |
| `install.html` | Página pronta de download + instalação (pode ser hospedada e/ou usada de base pelo site). Trocar `#BAIXAR_APK#` pela URL real do APK e o wordmark pela logo full HD |
| `COMO_FUNCIONAM_OS_TORNEIOS.md` | Como funcionam os torneios, como participar, planos, entradas e prêmios (conteúdo para o site) |
| `KIT_MARCA_E_SITE.md` | Cores exatas (HEX), tipografia e direção visual para o site combinar com o app |

## Modelo de distribuição (alinhamento com a agência)
- O app é distribuído por **link direto** (arquivo `.apk`), **não pela Play Store**.
- O anúncio aponta para a **página de download** (base em `install.html`), que será
  hospedada. O link final do APK entra no lugar de `#BAIXAR_APK#`.
