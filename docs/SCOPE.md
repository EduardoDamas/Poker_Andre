- Texas Hold'em poker engine (betting rounds, hand ranking, side pots) — **server-authoritative**.
- Real-time multiplayer: join/leave a table, state sync, reconnection.

- Registration/login: **phone OTP** + Facebook; **CPF validation** + **18+ block**.

- Prize distribution following the document's table (room occupancy %, levels, eliminatory phases).
